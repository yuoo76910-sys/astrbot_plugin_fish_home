# 鱼的窝 · astrbot_plugin_fish_home

一个 AstrBot 插件：给你的机器人搭一间**能住人的像素小窝**。她有自己的心情、好感度、工资和晚饭；你在聊天里说的话她都会记账，房间里摆了什么东西她也知道。

当前版本 **v0.2.3**。详细玩法与安装见 [README_发布说明.txt](README_发布说明.txt)。

## 它是什么

- **养成**：好感度按每句话实时结算（认真说话涨、凶她掉），赌气和「屋里没有人」都是真的。
- **生活**：每天有工资、会做饭吃饭、吃多了同一种会腻；晚上可能给你写信（信箱，一周最多两封，可加急）。
- **DIY**：一句话描述 + 你打的分（−10~+20），她按自己的口味表决定惊喜还是嫌弃。
- **家具工坊**：一句话 → AI 出像素家具 → 拖进房间随便摆。
  - 两条生成路线：LLM 施工图（默认，零新增 key）／精绘模式（接一个生图 API，兼容 OpenAI-style 与火山方舟 Ark，豆包 Seedream 可直接用；本地自动抠图/降采样/限色/描边）。
  - 想画什么就画什么：家具、动物、食物、一张脸——主体完全跟着你的描述走。
  - 叠放：松手的永远在最上层，右键压到最底，位置、大小、层序全部存档。
  - 她知道屋里有什么：画成、首摆会按人设主动提一嘴，删除则静默遗忘。

## 安装

1. 需要 **astrbot_plugin_fish_heart**（她的心情、九维、责难数据源；没装的话面板能开但状态恒为默认）。AstrBot 插件市场搜 `fish_heart` 安装，或用作者的仓库地址。
2. 把本仓库克隆/解压到 AstrBot 的 `data/plugins/astrbot_plugin_fish_home/`。
3. 重启 AstrBot，后台插件列表 → 鱼的窝 → 点「页面」打开小窝。

升级直接整目录覆盖，存档在 `data/plugin_data/astrbot_plugin_fish_home/`，不会丢。

## 配置

设置项都在插件配置里（`_conf_schema.json` 有说明），关键几处：

- `主人会话`：好感度、离线补看、信件只对这一个会话生效。
- `家具工坊 · 精绘模式`：生图 api_key / base_url / model。留空 = 用默认 LLM 施工图路线；填了才启用精绘。Ark 的 AgentPlan 套餐 key 记得把 base_url 填成 `.../api/plan/v3`。
- `furn_gen.daily_limit / max_items`：默认 0 = 不限次。

密钥只存在你自己的 AstrBot 配置文件里，仓库和插件目录都不含任何 key。

### v0.2.3 — 2026-11-14
- 修复：按市场上下文注入规范，逐轮变化的动态状态提示（好感/心愿/记忆/离线补看等）不再拼接进 system prompt，改为临时用户消息片段（`extra_user_content_parts` + `mark_as_temp`），不再破坏前缀缓存命中。
- 变更：数据目录获取失败时直接报错终止加载，不再静默回退到插件目录（避免整包升级连带丢存档）。

### v0.2.2 — 2026-11-13
- 修复：重新走 AstrBot 插件市场审核通道（v0.2.1 提交时因服务端超时导致版本号被占用），功能代码与 v0.2.1 完全一致。
- 新增：`metadata.yaml` 补充 `repo` 字段（市场按它关联插件与仓库）。

### v0.2.1 — 2026-11-13
- 新增：工坊 · 精绘模式（可选）——接入生图 API（默认硅基流动，兼容火山方舟 Ark AgentPlan 套餐），本地自动抠图 / 降采样 / 限色 / 描边，产出与施工图同规格的像素家具；接口失败自动退回施工图，Key 留空照常玩。
- 新增：她知道自己屋里有什么——画成、首次摆放会按人设主动提一嘴；删除静默遗忘；吃过的和画过的分开记账。
- 变更：工坊主题放开——想画什么画什么（家具、动物、食物、一张脸），主体完全跟随描述。
- 变更：叠放规矩——松手的最上层，右键（长按）压最底，层序持久化，普通视角与摆放模式一致。
- 修复：摆放模式与普通视角之间的家具错位（两种视图统一同一条地面带坐标源）。

### v0.2.0 — 2026-11-11
- 新增：家具工坊——一句话 → LLM 施工图（调色板 + 图元指令）→ 代码渲染像素家具；纯拖拽摆放、滚轮缩放 0.4~3×、摆位持久化；成就家具（食盆 / 地毯 / 观众牌）也能挪。
