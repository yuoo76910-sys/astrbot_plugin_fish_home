鱼的窝 · astrbot_plugin_fish_home v0.2.1
==========================================

【前置】
  需要 astrbot_plugin_fish_heart（她的心情、九维、责难都从那里读）。
  没装鱼心的话，面板能开，但她的状态会一直是默认值。

【安装】
  1. 解压出 astrbot_plugin_fish_home 文件夹，放到 AstrBot 的 data/plugins/ 下；
  2. 重启 AstrBot；
  3. 后台插件列表 → 鱼的窝 → 点「页面」打开小窝。

【升级（0.1.x / 0.2.0 → 0.2.1）】
  停 AstrBot（或后台「重载」本插件），用新文件夹整个覆盖，再启动/重载。
  存档都在 data/plugin_data/astrbot_plugin_fish_home/，不会被覆盖丢掉。
  注意：0.2.0 起新增的家具工坊接口必须重载插件才注册得上，光刷新网页没用。

【第一次打开】
  房间是空的，她站在中间。左上角状态牌：名字 / 心情 / 好感度 / 余额 / 心愿 / 今日句数。
  底部是物品栏，只有吃的。点她、或者点物品格再点她，就能喂。

【核心玩法】
  好感度
    实时的。每说一句话结算一次：认真说话 +1，超过 12 字更多，夸她、说软话再加一点；
    「嗯」「哦」「在」这类不算话；凶她 −1.5。每天最多涨 15，会一直存着，也能掉成负数。
      >= 10  正常
       < 10  赌气（她停在赌气那一帧不动）
       < 0   屋里没有人了，只能靠聊天一点点聊回来
  工资 / 余额
    每天结算一次，按她当天的状态折成工资打进余额（底薪 20，状态每高一分 +0.7，一天最多 90）。
    余额拿去换吃的、DIY、加急信。
  吃的
    白米饭免费，每 12 小时补一份（离线最多补四份），永远不会有「吃腻」。
    其余七种每种都有自己的吃东西动画；连着喂同一种会腻，腻了就播她自己那套嫌弃动画。
  DIY
    一句话描述 + 你自己打的分（−10 ~ +20）。分数决定她什么反应：
      >= 8 惊喜 / 1~7 正常 / 0 中性 / −1~−7 嫌弃 / <= −8 生气
    她的口味表会记住你爱放什么（辣、烫、甜……），对分数做 ±2 的微调。一天一次。
  信箱
    右上角「信」按钮。左边按月份列，没读的带红点；右边是横线信纸。
    她一周最多写两封（有 3 天间隔）。花 20 块余额可以加急一封。
  等你说完（默认开）
    你连发几条，她只答最后一条。会拦掉一部分请求，发现她不怎么回就先关掉这个开关。
  离线补看（默认开）
    你不在线时发的私聊，她上线后翻出来看，下次说话能接上。
    只有 NapCat / aiocqhttp 平台有历史消息接口；其他平台会自动跳过。

【家具工坊】
  右上角「具」按钮。写一句话描述想画的东西——不一定是家具，动物、食物、
  摆件、一张脸都行——她的聊天模型出一份「施工图」
  （调色板 + 矩形/椭圆/三角/线/镜像这些图元指令），代码把它渲染成像素家具：
  平涂、1px 深墨描边、不渐变不抗锯齿，色板 ≤8、画布 ≤48，跟房间现有家具同一套规格。
  用的就是她平时聊天那个模型，零新增 key；默认免费不限次
  （配置 furn_gen.daily_limit / max_items 填 0 = 不限，填正数可以重新限次）。
  摆放是纯拖动：托盘里按住拖进房间，松手在哪就贴在哪（不吸附格子）；
  房间上半算挂墙、下半算落地（自动让开底部）；拖动中滚轮向上放大、向下缩小
  （0.4~3 倍，逐件记住）；拖回托盘 = 收回。
  三件成就家具（食盆/拼接地毯/B站观众牌）解锁后也能随便挪、随便放大缩小。
  叠放规矩：松手落位的那件永远在最上层（后来者压前件）；右键（手机长按）一件
  把它压到最底；从没手动摆过的按深度排（屏幕越靠下越靠前）。摆放模式和普通
  视角的显示完全一致，退出模式不会错位。
  自定义家具是纯装饰：不进成就、点了没反应，就是摆着好看。
  施工图是唯一真源：换风格可以反复「换一张」，保存后想改只能重画，没有手动编辑。

【v0.2.1 新增：工坊 · 精绘模式（可选）】
  设置 → 家具工坊 → 精绘模式，填一个生图 API Key（默认按硅基流动写的，
  火山方舟/豆包也直接兼容，接口地址和模型名都填配置里，随时可换）——
  工坊就会改用生图模型画这句话，然后本地完成：四边抠纯色背景（像素安全，
  不用 rembg 那类 AI 抠图）→ 降采样到 ≤48 → 量化 ≤8 色 → 自动描边，
  产出跟施工图完全同规格的像素家具，摆放系统一点没变。
  · Key 留空 = 一切照旧（LLM 施工图，默认）；填了才启用。
  · 精绘一次十几秒、按张计费/花套餐 token；想关就清掉 Key。
  · 生图接口失败会自动退回施工图保底，不浪费那次生成，提示里带原因。
  · 精绘件没有施工图（真源就是那张图本身），换风格 = 再生成一次。
  · 主体完全跟着你那句话走：「一张人脸」「一只橘猫」直接出脸出猫；
    想要猎奇组合就自己写关系，如「一张人脸印在沙发靠背上」。

【v0.2.1 新增：她知道自己屋里有什么】
   工坊里画成保存、或第一次把某件摆进房间，她会按自己的人设主动跟你
   提一嘴（用的是聊天模型，模型不可用时保持安静，不发模板句）。
   平时聊天她也知道你房间里摆着什么；删掉一件她立刻忘掉，不会追问。
   吃过的和画过的分开记，两边的回忆不会互相串。

【换美术】
  views/reward/assets/skin/skin.json 里登记了角色、窗外、房间、家具、DIY 图标的文件名。
  换图只改这张表，不用动代码。

【数据在哪】
  data/plugin_data/astrbot_plugin_fish_home/state.json            主存档
  data/plugin_data/astrbot_plugin_fish_home/custom_furniture.json 家具工坊的库（施工图）
  data/plugin_data/astrbot_plugin_fish_home/furniture_imgs/       渲染出来的像素 PNG
  想从头开始玩，删掉 state.json 即可（samples/ 里有一份「正常玩法」示例存档，
  复制过去改名 state.json 就是有进度的样子）。插件整包升级这些都不丢。

【已知】
  · 窗外动图与天气只对应 4 档（晴/雨/雪/夜），阴天雾天走晴；
  · 屋里的背景永远是开灯状态；
  · 好感度、离线补看、信件只对配置里填的「主人会话」生效；
  · 「AI 生成」的家具是代码用图元画的，出来是平涂的代码感像素小件，不是手绘质感；
    不满意就点「换一张」，同一句话每次构图都不一样；嫌糙就开精绘模式（见上）；
  · 家具工坊依赖聊天模型回复质量，模型偶尔会乱答，那时会提示重新生成，不计废一次机会。
